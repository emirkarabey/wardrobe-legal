# wardrobe-legal

The privacy policy and terms of use for the MyWardrobe app, in Turkish and
English, published with GitHub Pages.

| | Türkçe | English |
|---|---|---|
| Privacy | [privacy.html](https://emirkarabey.github.io/wardrobe-legal/privacy.html) | [privacy.en.html](https://emirkarabey.github.io/wardrobe-legal/privacy.en.html) |
| Terms | [terms.html](https://emirkarabey.github.io/wardrobe-legal/terms.html) | [terms.en.html](https://emirkarabey.github.io/wardrobe-legal/terms.en.html) |

This repository exists only to make those four pages reachable. The app itself
is private; App Store Review Guideline 5.1.1(i) requires the privacy policy to
open from inside the app, and free GitHub Pages only serves public
repositories — so the documents live here rather than in the app repository.

**These files are the only copy.** The app repository points at these URLs
(`src/constants/legal.ts`) and keeps no duplicate, because two copies of a
privacy policy drift and the live one is the one that counts. Edit here.

`.nojekyll` turns the Jekyll build off, so the `.html` paths the app links to
are served exactly as they are written.
